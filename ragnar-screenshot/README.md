# ragnar-screenshot

**Deutsch:** Modernes Screenshot-Tool für LieraOS Ragnar — GTK4/libadwaita,
Wayland-nativ über wlr-screencopy (labwc). Modi: alle Monitore zusammen,
einzelner Monitor oder freie Bereichsauswahl (Dim-and-Reveal-Overlay).
Optionen: Mauszeiger, Ton, Verzögerung. Vorschau mit Speichern (PNG),
Bearbeiten (Markieren/Schwärzen) und Erneut. Ersetzt den alten
Screenshot-Dialog.

**English:** Modern screenshot tool for LieraOS Ragnar — GTK4/libadwaita,
native Wayland via wlr-screencopy (labwc). Modes: all monitors merged,
single monitor or free area selection (dim-and-reveal overlay). Options:
pointer, sound, delay. Preview with save (PNG), edit
(highlight/redact) and retake. Replaces the old legacy screenshot
dialog.
