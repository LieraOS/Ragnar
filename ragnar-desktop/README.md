# ragnar-desktop

## Deutsch

Session-Glue-Paket für Ragnar (LieraOS). Enthält die Launcher-Skripte,
die labwc-Bridge, GSettings-Schemas, Icons und Daten. Alle
Desktop-Komponenten sind eigenständige Rust-Crates — hier gibt es
keinen kompilierten Code.

## English

Session glue package for Ragnar (LieraOS). Contains launcher scripts,
the labwc bridge, GSettings schemas, icons and data. All desktop
components are separate Rust crates — there is no compiled code here.
