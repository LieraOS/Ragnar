# Screenshots

Drop PNG screenshots of the running Ragnar desktop here. The root
README references four files — rename/adjust there as needed:

- `desktop.png`  — full desktop with taskbar
- `settings.png` — Ragnar Settings
- `heimdall.png` — Heimdall network UI
- `apps.png`     — any app view (Valkyrie, game launcher, …)

Keep them reasonably sized (~1-2 MB, 1920x1080 or smaller);
GitHub renders them from this directory.
